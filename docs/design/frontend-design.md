# Frontend design direction

The interface uses the existing Plum purple as its only accent and keeps the original claim submission and review flows intact. The layout is a low-motion, high-density enterprise workspace built for quick scanning at 1440px and a deliberate single-column collapse on mobile.

Two product references guided the update:

- Linear: compact top navigation, restrained borders, clear selected states, and dense lists that remain readable.
- Stripe Dashboard: aligned summary metrics, evidence-first record detail, and progressive disclosure for supporting decision facts.

The operations portal is a local demonstration surface. It labels that limitation directly and does not claim production authentication or access control.
